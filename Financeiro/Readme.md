# Dashboard Financeiro | Power BI

## Sobre o projeto

Este projeto consiste em um dashboard financeiro desenvolvido no Microsoft Power BI, com o objetivo de transformar dados financeiros em informações visuais que facilitem o acompanhamento e a análise dos resultados.

A solução busca proporcionar maior visibilidade das informações financeiras, apoiar o monitoramento de indicadores e auxiliar no processo de tomada de decisão.

## Objetivos

- Organizar e analisar informações financeiras.
- Facilitar o acompanhamento dos resultados.
- Identificar tendências e variações financeiras.
- Melhorar a visualização e interpretação dos dados.
- Apoiar a tomada de decisões baseada em dados.

## Tecnologias utilizadas

- Microsoft Power BI
- DAX
- Power Query
- Power BI Project (PBIP)

## Estrutura do projeto

- `.pbip`: arquivo principal do projeto Power BI.
- `.Report`: definições do relatório e elementos visuais.
- `.SemanticModel`: modelo semântico, relacionamentos e medidas.
