# 📊 Portfólio Power BI

Repositório dedicado a projetos de **Business Intelligence e Análise de Dados**, aplicando técnicas de transformação e modelagem de dados, criação de medidas e indicadores, desenvolvimento de dashboards interativos e visualização de informações para apoiar a tomada de decisões.

### 🛠️ Tecnologias e Habilidades

* **Power BI:** desenvolvimento de relatórios e dashboards interativos.
* **DAX:** criação de medidas, cálculos e indicadores de desempenho (KPIs).
* **Power Query (M):** extração, limpeza e transformação de dados (ETL).
* **Modelagem de Dados:** relacionamentos, estruturação e organização de modelos analíticos.
* **SQL:** consultas, extração e manipulação de dados.
* **Data Visualization:** apresentação de dados de forma clara, intuitiva e orientada ao negócio.
